# Yash Raj — Aarab-inspired Portfolio

A local class-project portfolio using an original dark developer theme inspired by the structure and visual language of aarab.me.

Includes:
- numbered navigation/sections
- large editorial hero
- About
- Skills marquee and cards
- Education
- Work/Projects
- Certificates
- Contact
- Calculator, To-Do List and Digital Clock demos
- Air Quality Management System featured project

Run `index.html` with VS Code Live Server.
